# Структура сайта UBuyer — SEO-архитектура

## Логика

Сайт работает на трёх уровнях трафика:
- **Горячий** — человек уже ищет "самовыкупы WB" → главная, страницы услуг
- **Тёплый** — ищет решение проблемы "карточка не растёт" → сценарии, кейсы
- **Холодный** — ищет информацию "как поднять позиции WB" → блог, лид-магниты

## SEO-приоритеты на старте

**Фаза 1 — главная + сценарии** (делаем сейчас)
- Главная под запрос "самовыкупы wildberries"
- 3 ключевых сценария

**Фаза 2 — блог**
- 4-5 статей под информационные запросы
- Каждая статья ведёт на сценарий или форму

**Фаза 3 — лид-магниты**
- Калькулятор ДРР (самый горячий)
- Бесплатный разбор карточки

## Технические требования для SEO

- Каждая страница: уникальный title + description
- H1 содержит ключевой запрос
- Внутренняя перелинковка: блог → сценарии → главная → заявка
- Breadcrumbs на внутренних страницах
- Schema.org разметка: Organization, FAQPage, BreadcrumbList
- Sitemap.xml
- Скорость: Core Web Vitals Green
