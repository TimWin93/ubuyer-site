# Layout Composition

## Core Rule

Think in scenes, not blocks.

Each screen needs:

- one hero object;
- one support layer;
- one conversion direction.

## Composition Principles

- strong single-column mobile logic;
- dense but breathable stacking;
- obvious visual center;
- compact support modules around the center;
- clear downward rhythm.

## Screen Composition

### Screen 1

- top framing element or progress;
- large headline zone;
- central entry card;
- AI assistant hint nearby;
- trust row below;
- CTA anchored clearly.

### Screen 2

- result card dominates;
- controls directly connected to result;
- AI explanation visually tied to estimate;
- support info in secondary modules;
- CTA visible without confusion.

### Screen 3

- form card dominates;
- trust and next-step reassurance close to form;
- contact-method choice visually simple;
- success state calm and conclusive.

## Spacing Logic

- preserve compact mobile rhythm;
- avoid giant empty vertical gaps;
- use spacing to signal hierarchy, not just separation.
