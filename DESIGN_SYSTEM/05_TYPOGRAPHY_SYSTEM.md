# Typography System

## Typography Goals

Typography should feel:

- premium;
- controlled;
- expressive in headings;
- efficient in UI.

## Rules

- heading style must have character;
- body and UI text must remain highly readable;
- avoid default-template feeling;
- use strong contrast between display text and support text.

## Hierarchy

- H1: bold, compact, high authority;
- H2: explanatory but still strong;
- body: short and practical;
- labels: concise and useful;
- trust text: quiet but clear.

## What to Avoid

- generic neutral tech startup typography;
- too many font families;
- weak or tiny headings on mobile;
- overly airy spacing that kills conversion energy.
