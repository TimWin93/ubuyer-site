# Anti-Patterns

Forbidden or strongly discouraged:

- generic SaaS gradient background
- bland rounded cards with no character
- identical buttons with no hierarchy
- fade-in everywhere
- random blur and glow with no logic
- default Inter + Tailwind starter look as final output
- too much text on the first screen
- icons for the sake of icons
- weak CTA with vague copy
- equal depth on all elements
- flat UI with no light, mass, or tactile response
- “bank dashboard” feeling instead of emotional product feel
- AI widget glued onto the corner with no funnel role
- excessive glassmorphism
- decorative 3D that hurts readability
- generic startup hero with abstract shapes and no product object
- motion that looks expensive but says nothing

If a design starts to feel:

- safe,
- generic,
- template-like,
- overclean,
- “just modern”,

then it is already drifting in the wrong direction.
