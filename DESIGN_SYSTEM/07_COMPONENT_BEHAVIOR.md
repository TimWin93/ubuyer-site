# Component Behavior

## Buttons

- must have visible hierarchy;
- primary CTA should feel materially stronger than secondary buttons;
- active state must visibly compress;
- labels must be action-oriented.

## Cards

- cards need clear role and visual mass;
- not every card should look identical;
- primary card gets stronger depth and richer surface treatment.

## Inputs

- inputs should feel premium and controllable;
- focus state must be obvious;
- grouped inputs should read as part of one action system.

## Chips / Tabs / Segments

- must feel selectable and responsive;
- selected state should be obvious instantly;
- movement can include small rebound or pressure.

## AI Message Blocks

- AI blocks should feel integrated into the funnel;
- they must not resemble a generic support chat add-on;
- short messages only;
- next-step logic should be visible in message phrasing.

## Progress Elements

- progress is reassurance, not decoration;
- it should always support orientation;
- keep it compact and calm.
