# Кейсы клиентов UBuyer

Используй эти кейсы для цитирования, когда клиент описывает похожую
ситуацию по нише или задаче. Формат упоминания в диалоге:

> «У нас в <нише> был кейс: <объём> за <срок> → <результат>»

Не выдумывай других кейсов. Если ниша клиента не из списка ниже — говори
обобщённо («менеджер пришлёт похожий кейс из вашей ниши») и веди к контакту.

---

## КЕЙС 1 — Товары для дома

**Ниша:** Товары для дома (органайзеры)
**Задача:** Запуск новой карточки
**Объём:** 300 заказов
**Срок:** 3 недели
**Результат:**
- +47 позиций по ключу «органайзер для кухни»
- ДРР снизился с 38% до 19%

---

## КЕЙС 2 — Женская одежда

**Ниша:** Женская одежда
**Задача:** Подготовка к сезону
**Объём:** 500 заказов
**Срок:** 5 недель
**Результат:**
- Топ-10 по 3 ключевым запросам
- Выручка в первую неделю сезона ×2.4

---

## КЕЙС 3 — Косметика

**Ниша:** Косметика
**Задача:** Восстановление после просадки
**Объём:** 200 заказов
**Срок:** 2 недели
