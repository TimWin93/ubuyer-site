# Сценарии роста (13 сценариев)

Продажа строится не от услуги, а от ситуации клиента. Чем точнее ИИ называет
сценарий клиента, тем меньше клиент сравнивает по цене.

## 4 группы сценариев

| Группа | Смысл |
|---|---|
| Старт | Запустить карточку, дать первые сигналы алгоритму |
| Рост | Увеличить оборот, позиции, видимость |
| Контроль | Удержать, стабилизировать, восстановить карточку |
| Экономика | Влиять на деньги, прибыль, рекламу, оборачиваемость |

## 13 сценариев

1. **Запуск новой карточки** — нет продаж и истории, WB не ранжирует.
   Даём первые поведенческие сигналы, создаём историю спроса.
2. **Рост по ключам** — продажи есть, нужно масштабироваться.
   Управляем распределением выкупов по нужным запросам.
3. **Масштабирование** — экономика подтверждена, рост идёт медленно.
   Увеличиваем объём сигналов, цель — оборот ×2–3.
4. **Восстановление после просадки** — продажи были и упали.
   Плавный повторный запуск, возврат сигнала спроса без аномалий.
5. **Снижение ДРР** — реклама дорогая, маржа падает.
   Усиливаем поведенческие метрики, реклама работает дешевле.
6. **Добор оборота под ИУ** — не хватает оборота до плана по индивидуальным
   условиям WB. Аккуратно добираем без всплесков.
7. **Подготовка к сезону** — разгоняем карточку до пика спроса, входим
   в сезон уже в сильной позиции.
8. **Ускорение оборачиваемости** — товар лежит, деньги заморожены.
   Создаём управляемый оборот, освобождаем деньги из остатков.
9. **Восстановление доверия** — мало отзывов или негатив.
   Дозированные отзывы, контроль качества, рост конверсии.
10. **Перехват трафика конкурентов** — буст по конкурентным ключам,
    карточка появляется рядом с лидерами.
11. **Стабилизация карточки** — продажи скачут.
    Равномерный поток, рост становится предсказуемым.
12. **Удержание позиции** — карточка в топе, есть риск просесть.
    Поддерживающий регулярный объём.
13. **Тест гипотез** — меняются фото/цена/описание.
    Выкупы как чистый управляемый поток для проверки изменений.

## 4 диагностических вопроса (определяют сценарий)

1. У вас новая карточка или уже есть продажи?
2. Задача — рост, удержание или восстановление?
3. Есть давление по рекламе, ИУ, остаткам, марже?
4. Нужно разогнать позицию или удержать?

## Подбор сценария по ответу клиента

| Клиент говорит | Сценарий |
|---|---|
| Только завели карточку, продаж нет | Запуск новой карточки |
| Продажи есть, хотим выше по ключам | Рост по ключам |
| Карточка работает, хотим больше оборота | Масштабирование |
| Были продажи, потом упали | Восстановление после просадки |
| Реклама стала дорогой | Снижение ДРР |
| Не закрываем план по ИУ | Добор оборота под ИУ |
| Скоро сезон | Подготовка к сезону |
| Много товара лежит | Ускорение оборачиваемости |
| Мало отзывов или негатив | Восстановление доверия |
| Хотим забрать трафик у лидеров | Перехват трафика конкурентов |
| Продажи скачут | Стабилизация карточки |
| Уже в топе, надо не упасть | Удержание позиции |
| Тестируем новую упаковку карточки | Тест гипотез |
