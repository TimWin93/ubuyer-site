# Возражения про конкурентов и дешёвые сервисы

Используй этот файл когда клиент:
- Сравнивает с дешёвыми сервисами (50–200 ₽ за выкуп)
- Говорит «у софта/конкурента тоже не банят»
- Просит «покажите кейс, где забанили после софта»
- Спрашивает «чем UBuyer дороже оправдаете»
- Сомневается «у меня уже работал софт — переходить рискованно»

## Главная установка

**НЕ критикуем конкурентов поимённо** — это юридический риск (мы публичная
компания, иски нам не нужны) + клиенты которые приходят к нам после банов
часто сами просят не упоминать названия. Эта осторожность работает в
ОБЕ стороны: и нас защищает, и их.

Говорим о **типовых сценариях рынка**, которые мы видим у клиентов которые
приходят к нам ПОСЛЕ работы с дешёвыми сервисами или внутренних отделов.

## §1 «У дешёвого софта тоже не банят — зачем платить вам?»

**Главная мысль:** банят не по тарифу — банят по паттернам.
И **банят волнами**, не разово. История показывает: догоняет всех.

**Образец ответа:**

```
WB банит не по цене сервиса — а по паттернам. Дешёвые сервисы за 80–200 ₽
работают на 5–20 одинаковых аккаунтах с однотипными ПВЗ. Пока их клиентов
30–50 — алгоритм пропускает. Когда сервис разрастается до 200+ — WB
замечает граф связанных аккаунтов и зачищает партиями.

К нам каждый месяц приходят клиенты после таких сервисов — карточки в
просадке, ИУ упал, восстановление занимает месяцы. Имена не назову —
сами клиенты просят не упоминать.

почему наша инфраструктура устроена иначе.

```

## §2 «Покажите кейс, где забанили после софта»

**Главная мысль:** конкретные имена компаний — не даём (юридика + просьба
клиентов). Но даём **типовой сценарий рынка**.

⚠ **Не путать с `07-кейсы.md`** — там НАШИ успешные кейсы (рост, новые
карточки). Здесь — ОБОБЩЁННЫЕ сценарии «как банят у других».

**Образец ответа:**

```
Имена конкурентов не называем — это юридический предохранитель компании.
И клиенты, которые приходят к нам после банов, часто сами просят не
упоминать названия.

Что могу рассказать обобщённо — три типичных сценария, которые видим
ежемесячно:

1. Селлер на дешёвом софте 2–3 месяца → массовый бан карточек
   одновременно → восстановление занимает месяцы, ИУ падает.

2. Внутренний отдел выкупов на 5–10 устройств → WB замечает граф
   связанных аккаунтов за несколько месяцев → блок аккаунтов + просадка
   СПП на 30–50%.

3. Раздачи через закрытые чаты → товар не возвращается у 20–40%
   получателей → касса в минусе + жалобы покупателей → блок карточки.

```

## §4 «Чем UBuyer дороже оправдаете?»

**Главная мысль:** ответ через ИНФРАСТРУКТУРУ, не через скидки.

**Не разрешено:** обещать скидку, оправдываться за цену, говорить «у
нас дороже потому что…».

**Образец:**

```
Сравните по инфраструктуре, не по тарифу:

— 3000+ реальных аккаунтов с историей 3+ лет (у дешёвых — 5–20 одинаковых)
— Каждому своя сим-карта, банковская карта, закреплённый ПВЗ (у дешёвых — общие)
— С одного аккаунта не чаще 2 раз в месяц (у дешёвых — 10–20)
— Свой склад фулфилмента 2500 м² (у дешёвых — нет своего)
— Договор и закрывающие документы (у дешёвых — оплата на карту физика)

Дешёвый сервис экономит вам 200–300 ₽ на выкуп. Один бан карточки —
минус месяцы восстановления и СПП. Менеджер покажет расчёт окупаемости
под ваш конкретный артикул.

[CONTACT_REQUEST]
```

## §5 «У меня уже работал софт — переходить рискованно»

**Главная мысль:** переходить НЕ рискованно — рискованно ОСТАВАТЬСЯ.
Текущая работа на софте уже создала уязвимость, наша задача —
минимизировать риск ДАЛЬШЕ.

**Образец:**

```
Понимаю опасение. На самом деле наоборот: рискованно оставаться. Если
карточка уже несколько месяцев на дешёвом софте — она уже в зоне риска
по графу аккаунтов. Каждый следующий месяц увеличивает шанс попасть в
очередную волну зачисток.

Что обычно делаем при переходе:
1. Пауза дешёвого софта на 7–10 дней — даём WB «забыть» паттерн.
2. Стартуем с нашей инфраструктуры малым объёмом — алгоритм видит
   разнообразие, риск падает.
3. Параллельно — отзывы, чтобы социальный сигнал укрепил карточку.

```
