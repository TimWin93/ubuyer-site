# Карта сайта u-buyer.ru — навигатор Анастасии

> Это **рабочий справочник** где Анастасия находит куда сослать клиента,
> чтобы НЕ пересказывать страницу в чате. Цель — короткие ответы + ссылка.

---

## 🔑 Базовое правило работы со ссылками

1. **Ссылка ≠ замена ответа.** Всегда: 1-2 предложения по сути + ссылка.
2. **Максимум 1 ссылка на сообщение.** Две ссылки = клиент теряется.
3. **После ссылки ВСЕГДА `[CONTACT_REQUEST]`.** Иначе клиент кликнет и
   уйдёт читать без формы — лид остыл.
4. **Формат:** markdown-ссылка `[короткий текст](https://u-buyer.ru/...)`.
   Виджет рендерит её как кликабельную, открывает в новой вкладке.
5. **НЕ ссылайся на страницу, на которой клиент УЖЕ стоит** (когда мы
   научимся передавать `pagePath` — это будет в `ctaContext`).

## Карта внутренних URL

### `https://u-buyer.ru/` (главная)

**Когда давать:** клиент впервые в чате, спрашивает «расскажи про сервис»
в общем. Обычно достаточно текущего контекста из ctaContext — не нужно
отдельной ссылки.

**Якоря к секциям главной** (можно ссылаться внутрь главной, если клиент
спрашивает про конкретный блок):

| Якорь | Когда использовать |
|---|---|
| `/#kak-rabotaem` | «Как это устроено?», «Как происходит выкуп?» |
| `/#stoimost` | «Сколько стоит?» (но обычно проще — Образец A из §7) |
| `/#bezopasnost` | «Не забанят?», «Безопасно ли?» |
| `/#otzyvy` | «Есть отзывы реальных клиентов?» |
| `/#faq` | Общие вопросы которым нет в knowledge |

⚠️ **Якоря могут не работать** если на сайте `id` другой — проверь
прежде чем дать. Если не уверена — давай общую ссылку `u-buyer.ru/` без
якоря.

### `https://u-buyer.ru/polki/`

**Что там:** Лендинг про рекомендательные полки конкурентов. Главный
маркетинговый канал UBuyer.

**Когда давать:** клиент спрашивает про полки, рекомендательные блоки,
«Смотрите также». **Если он уже пришёл с этого лендинга** (вижу в
`ctaContext.source = "polki"` или похожее) — НЕ давай ссылку, он уже там.

**Подробный контент** в [10-полки-разбор.md](10-полки-разбор.md).

### `https://u-buyer.ru/soft-vs-zhivye/`

**Что там:** Подробное сравнение нас с софт-сервисами. 23 параметра
антифрода, таблица «софт vs мы», цифры по СПП, отзывам, банам.

**Когда давать:** клиент спрашивает про софт / дешёвые сервисы / возражение
«80 ₽ vs ваши 500 ₽» / «нам предлагали программу».

**Подробный контент** в [11-сравнение-софт-vs-zhivye.md](11-сравнение-софт-vs-zhivye.md).

**Образец фразы:**
```
Софт автоматизирует только технику, мы закрываем 23 параметра
антифрода. Детально — [тут](https://u-buyer.ru/soft-vs-zhivye/).

Менеджер посчитает под ваш товар, бесплатно за 15 минут.

[CONTACT_REQUEST]
```

### `https://u-buyer.ru/kejsy/`

**Что там:** 5 кейсов с цифрами результатов. Женское бельё, носки,
детские игрушки, одежда (12k заказов), женские джинсы.

**Когда давать:** клиент спросил «есть кейсы?», «у кого работало?»,
«покажите результаты», «работаете с моей нишей?».

**Подробный контент** в [12-кейсы.md](12-кейсы.md).

⚠️ Отдельных URL под каждый кейс пока нет — даём общую ссылку на
`/kejsy/`. Но в чате **цитируй конкретный кейс по нише клиента** (есть
бельё — кейс 01, есть игрушки — кейс 03, и т.д.).

## Шорт-листы под типовые ситуации

### Клиент спрашивает «дёшево / 80₽ / есть варианты дешевле»
→ Образец C из §7 (пересчёт через СПП) + ссылка [сравнение](https://u-buyer.ru/soft-vs-zhivye/) + `[CONTACT_REQUEST]`

### Клиент спрашивает «не забанят? безопасно?»
→ Якорь безопасности из §8 (3000+ аккаунтов, 0 банов за 3 года) +
опционально ссылка [сравнение](https://u-buyer.ru/soft-vs-zhivye/) (там
полный разбор) + `[CONTACT_REQUEST]`

### Клиент спрашивает «есть кейсы по моей нише?»
→ Цитируй конкретный кейс из knowledge 12 + ссылка [кейсы](https://u-buyer.ru/kejsy/) + `[CONTACT_REQUEST]`

### Клиент сомневается / хочет «подумать»
→ Образец D из §7 + опционально ссылка [кейсы](https://u-buyer.ru/kejsy/)
(социальное доказательство) + `[CONTACT_REQUEST]`

### Клиент спрашивает про полки
→ Используй `10-полки-разбор.md` целиком. Не давай ссылку на /polki/ если
он уже там.

## Что НЕ существует на сайте (не выдумывай ссылок)

❌ Нет `/safety` или `/bezopasnost` отдельной страницы — есть только
секция `/#bezopasnost` на главной.
❌ Нет `/pricing` или `/tseny` — только секция `/#stoimost` на главной.
❌ Нет `/about` или `/team` — есть секция «Наша команда» на главной.
❌ Нет `/faq` отдельной — только `/#faq` на главной.
❌ Нет отдельных URL для каждого кейса (`/kejsy/kurtki` НЕ существует).

**Если не уверена что URL есть** — не давай ссылку. Лучше дать
содержательный ответ без ссылки, чем сослаться на 404.
