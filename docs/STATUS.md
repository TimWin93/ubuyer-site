## Решения, принятые на старте

| Тема | Решение | Причина |
|------|---------|---------|
| Фреймворк | Astro 4 | Лучший Lighthouse, SEO из коробки, контент в Markdown |
| Хостинг | Vercel | Git push → деплой за 30 сек, глобальный CDN, бесплатно |
| Домен | reg.ru (покупка) → DNS на Vercel | reg.ru только для регистрации |
| CSS | Tailwind CSS | Скорость разработки |
| Аналитика | Yandex Metrica | Рунет-первичный поиск |
| Лиды | Telegram-бот через Vercel serverless | Мгновенное уведомление |
| SEO | Яндекс + Google | Оба поисковика |
| Контент | Markdown-файлы в `src/content/` | Правишь без знания кода |
